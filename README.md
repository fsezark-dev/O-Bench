# O-Bench
O-Bench is a modular research-oriented framework for benchmarking and analyzing metaheuristic optimization algorithms on NP-hard combinatorial optimization problems. The project provides a unified environment for evaluating algorithmic performance, convergence dynamics, runtime efficiency, robustness, and scalability across multiple problem domains.

The framework currently supports the Traveling Salesman Problem (TSP) and the 0/1 Knapsack Problem, enabling systematic comparison of search strategies under controlled experimental conditions.
